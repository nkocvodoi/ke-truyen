Kệ Truyện

Mở cả folder ảnh truyện trong app Files rồi lướt từng trang, xếp đúng thứ tự 1, 2, 3 … 10, 11.

Cách mở folder trên iPhone

  1. Bấm Chọn ảnh hoặc file .zip, rồi chọn Chọn tệp (Choose File).
  2. Vào folder truyện, bấm Chọn (Select) ở góc trên bên phải.
  3. Bấm Chọn tất cả (Select All), rồi bấm Mở (Open).
  4. Đọc: chạm giữa màn hình để hiện thanh công cụ, kéo thanh trượt để nhảy trang.
Mẹo nhanh hơn: trong Files, nhấn giữ folder truyện → Nén (Compress). Bạn sẽ có file .zip, chỉ cần chọn đúng một file đó là mở được cả bộ. File .cbz cũng mở được.
